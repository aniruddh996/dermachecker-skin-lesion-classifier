About Product

A demo, not a diagnosis.

DermaChecker is a personal project exploring AI in dermatology — a DenseNet121 CNN fine-tuned by transfer learning to sort dermoscopic images into seven lesion types.

What it is

A transfer-learning classifier

Built on DenseNet121 and fine-tuned on the HAM10000 dermoscopic image set, DermaChecker takes a photo of a skin lesion and returns the model's best guess across seven categories, from benign moles to melanoma-adjacent classes — with a confidence score for each.

Why it exists

Curiosity about AI in healthcare

I built the first version of this a few years ago to explore what transfer learning could do on a real medical imaging problem. This revived version fixes the original deployment bugs and reconnects it to the real trained weights — same model, working demo.

Disclaimer

DermaChecker is a personal machine learning project, not a medical device. It was built to explore transfer learning on a dermatological imaging dataset (HAM10000) and is shown here as a portfolio demo.

Its predictions are not clinically validated, have not been reviewed by a dermatologist or regulatory body, and should never be used to diagnose, rule out, or make decisions about a real skin condition — including melanoma. If you're concerned about a mole or lesion, please see a licensed dermatologist.

While reviving this project I traced a labeling bug in the original training notebook: a copy-paste typo mapped melanoma images ('mel') to the string "dermatofibroma" instead of "melanoma" when building the training labels, so one of the model's seven output classes was trained on real melanoma photos under the wrong name. This demo corrects the displayed label for that class to Melanoma rather than hiding the issue — worth knowing if you extend or retrain this model.
